# Meta Ads Marketing Report & Business Analytics Tool

A modern, high-performance web application designed for digital marketers, media buyers, and financial analysts to track Meta Ads performance, monitor conversion funnels, and calculate business ROI.

## 💾 Persistent Data Input (Saved for Future Updates & Reports)

All campaign-level business conversion metrics entered manually by users are **automatically saved** in the browser's persistent LocalStorage (`meta_report_manual_data`). When you return to the application, refresh the page, or update date ranges and account selections, your inputs remain intact.

### 📌 Persisted Metrics:
- **Account Open (`accountOpen`)**: Total user registrations/accounts created per campaign.
- **Funded Accounts (`fundedAccounts`)**: Number of accounts with initial deposit/funding.
- **Deposit Amount (`deposit`)**: Total revenue/deposit amount ($ USD) generated by the campaign.
- **Daily Budget (`dailyBudget`)**: Target daily budget override per campaign for budget pacing calculations.

### 📤 Data Export & Backup Features:
- **Export Inputs**: Download your saved manual inputs as a structured `.json` file (`meta_report_manual_inputs_YYYY-MM-DD.json`).
- **Import Inputs**: Upload previously exported `.json` manual data files to easily transfer data across devices or restore past reports.
- **Clear Inputs**: Option to reset saved manual metrics when starting a fresh reporting period.

## 🚀 Key Features

- **Meta Ads Graph API Integration**: Automatically fetches ad account campaigns, spend, impressions, clicks, CTR, CPC, CPM, and lead conversions.
- **Currency Conversion**: Automatic live exchange rate conversion from multi-currency ad spend to USD.
- **Conversion Funnel Metrics**:
  - **CPA (Cost per Account Open)**: $\text{Spend} / \text{Account Open}$
  - **CPFA (Cost per Funded Account)**: $\text{Spend} / \text{Funded Accounts}$
  - **Lead to Account CVR**: $(\text{Account Open} / \text{Leads}) \times 100\%$
  - **Account to Funded CVR**: $(\text{Funded Accounts} / \text{Account Open}) \times 100\%$
  - **Overall Funnel CVR**: $(\text{Funded Accounts} / \text{Leads}) \times 100\%$
- **Financial & ROI Analysis**:
  - **Net Profit / ROI**: $((\text{Deposit Amount} - \text{Spend}) / \text{Spend}) \times 100\%$
  - Color-coded ROI indicator (Positive ROI in green, Negative in red).
- **Budget Control & Spend Pacing**: Tracks actual spend against expected target budget based on selected date ranges.
- **Reporting & Exporting**:
  - Export reports to **PDF** (via HTML2Canvas & jsPDF).
  - Print-friendly design for executive slide decks.
  - Interactive multi-tab reporting (Daily Breakdown, ROI Revenue Report, Funnel Health Report).
- **Organic Facebook Page Analysis**: Track page likes, impressions, top posts, and engagement.

## 📦 Getting Started

### 1. Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/hahaonguyen-spec/meta-report-tool.git
cd meta-report-tool
npm install
```

### 2. Environment Variables (Optional for Live Meta API)

Create a `.env` file in the root directory:

```env
VITE_META_ACCESS_TOKEN=your_meta_access_token_here
```

*Note: If no Access Token is provided, the tool operates seamlessly in Mock Data mode for demo and testing purposes.*

### 3. Local Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
